# 시골길 학습 때 도시 점수가 떨어진 이유와 수정 (사이클 4·5 → 6~)

진단 스크립트: `python tools/diagnose_forgetting.py weights/best.zip weights/cand_4_bc.zip ...` → `results/diagnosis_rural.json`
(아래 1~3의 숫자는 수정 전 코드·벤치마크 v1 기준으로 잰 값)

## 1. 무엇이 나빠졌나 (벤치마크 v1, 최고 모델 = 사이클 2 PPO)

| 시나리오 | 최고(사이클 2) | 사이클 4 시골길 BC | 사이클 5 시골길 PPO |
|---|---|---|---|
| rules_track (양방향·우측 차로 합성 트랙) | 66.8 완주 | **-24.8 출발 15 m 만에 이탈** | 66.6 |
| daechi_school_zone | 90.7 완주 | **-7.8 21% 지점 이탈** | 94.1 |
| hard_wet (젖은 노면) | 97.9 | 97.7 | **11.8 46% 지점 이탈** |
| gangnam_station 어린이보호구역 과속 | 1.45 s | 1.0 s | **2.7 s (+1.25, 허용 +1.0 초과)** |
| gangnam_traffic | 94.1 | **78.2 (과속 6.6 s)** | 90.7 |
| gangnam_reverse 신호·우회전 위반 | 0 | 1 | 1 |
| **도시 평균** | **74.25** | **52.16 (-22.1)** | **71.73 (-2.5)** |
| 시골길 평균 | 16.22 | 59.76 | 40.92 |

도시 평균 점수는 시나리오 10개 평균이라, 이탈 한 번(-40 + 완주 점수 손실 ≈ 시나리오 점수 -90~-105)이 평균을 약 9~10점 떨어뜨려요.
사이클 4의 -22점은 거의 다 이탈 두 번(rules_track, daechi) 때문이에요. 평가는 결정적이라(시드 0~3에서 같은 결과 확인) **잡음이 아니라 실제 회귀**였어요.

## 2. 원인 (숫자로 확인)

1. **도시 데이터가 줄어든 커리큘럼 (잊어버림)** — `sample_train_spec(stage=4)`로 뽑은 학습 데이터(기준 제어기로 달려 스텝 수로 잼):

   | | 시골길 | 실제 한국 도시 도로 | 합성 트랙(양방향 규칙 트랙 포함) |
   |---|---|---|---|
   | 단계 3 (도시 사이클) | 에피소드 4% / 스텝 5% | 36% / **47%** | 60% / 48% |
   | 단계 4 (시골길 사이클) | 51% / 43% | 16% / **26%** | 33% / 32% |

   도시 스텝 비율이 95% → 57%, 실제 도시 도로는 47% → 26%로 줄었어요. 게다가 DAgger 데이터는 **사이클마다 빈 상태에서 다시 모으고**
   최근 15만 개만 남겨서, 이전 사이클에서 배운 드문 도시 상황(양방향 우측 차로 급커브, 대치동 좁은 회전)을 다시 볼 기회가 적었어요.
2. **평균 오차로는 안 보이는 '폐루프' 오차** — 도시 상태(기준 제어기로 달린 상태)에서 흉내 오차(MSE)는 오히려 사이클 4가 더 작았어요
   (최고 0.026 → 사이클 4 BC 0.018). 하지만 rules_track 첫 굽이에서 조향을 기준 제어기보다 약 25% 덜 꺾어(0.29~0.35 vs 0.34~0.45)
   바깥으로 밀려 15 m 만에 이탈했어요. 최고 모델은 PPO로 조향을 기준보다 16% 세게 쓰는 쪽(급커브 이득 1.16)으로 맞춰져 있었는데,
   BC가 이것을 기준 제어기(1.00) 쪽으로 되돌리면서 **최고 모델이 실제로 통과하던 궤적**이 깨졌어요.
3. **PPO 단계가 조향을 흐트림 (사이클 5)** — 도시 상태 조향 오차가 BC 직후 0.0015 → PPO 뒤 **0.0357(24배)**. 시골길 보상(느린 속도·양보)과
   섞인 PPO가 정책을 크게 움직여 hard_wet 이탈.
4. **보상·관측 변경은 원인이 아님** — 사이클 2~5 모두 같은 관측(라이다 15 + 17개)·보상·벤치마크 v1로 학습·평가했어요.
   정책 입력은 정규화하지 않고(VecNormalize 없음) 환경이 고정 배율로 나눠요(속도/최고속도, 거리/30 m 등) → 정규화 통계가 바뀔 일이 없어요.
   시골길 상태는 도로 폭(-1.4σ), 밝기(-1.4σ), 앞차 거리(-1.2σ), 제한속도(-1.0σ)가 도시와 달라 네트워크가 구분할 수 있는 정도예요.
5. **별도 문제: OOD 통계** — `weights/obs_stats.npz`(자율 모드 '처음 보는 상황' 판단용)가 도시 사이클 데이터로만 만들어져서
   **시골길 상태의 75%를 OOD(z>6)로 판정**(도시 상태는 6%). 자율 모드가 시골길 밤길에서 출발하자마자 넘겨받던(자율 0%) 이유예요.
   승격에는 영향이 없지만, 이제 섞기 학습 데이터(도시+시골)로 통계를 만들어요.

## 3. 승격 관문 (`autodrive/bench.py` `compare`)

시나리오마다 (하나라도 걸리면 거절):
- 새로 이탈 (`n["crashed"] and not b["crashed"]`), 충돌 수 증가, 신호·우회전 일시정지 위반 수 증가
- 어린이보호구역 과속 `> 최고 + 1.0 s`, 완주율 `< 최고 - 0.05`, 시골길 위험 행동(위험한 엇갈림·보행자·앞지르기) 증가
- 시나리오 점수 `< 최고 - 5.0`

평균:
- 도시 평균 `< 최고 - 0.5` 이면 거절 (**수정**: `suite="all"`에서 시골길 평균이 +5 이상 오를 때만 `-1.0`까지 허용, `--urban-tol`)
- 비교 기준 점수(도시 사이클 = 도시 평균, 시골길 사이클 = 전체 평균) `< 최고 + 0.5` 이면 거절

허용치 근거: 도시 평균 1점 = 도시 10개 합 10점 = 예) 모든 도시 시나리오에서 평균 차선 오차 +0.2 m(5점/m), 또는 일반 과속 합 10초.
즉 승차감·효율 차이 수준이에요. 안전 항목(이탈·충돌·신호·우회전·어린이보호구역 과속·시골길 위험 행동)은 위의 시나리오별 조건이 그대로 막아요.

## 4. 수정

| 문제 | 수정 |
|---|---|
| 도시 데이터 감소 | `sample_mixed_spec`: 도시(실제 도시 도로 위주 70% + 합성 30%)와 시골길을 **50:50**으로 뽑고, DAgger 데이터를 도시/시골로 **따로 쌓아 미니배치마다 256+256으로 섞음** (시골길이 느려 스텝이 쏠리는 것도 막음). 쪽마다 최근 7.5만 개 |
| 최고 모델이 통과하던 도시 궤적이 깨짐 | **anchor(정책 고정 규제)**: 도시 상태에서 새 정책 평균 행동을 이전 최고 정책(고정) 평균 행동에 묶는 항 `anchor_w · ‖μ_new − μ_best‖²` (같은 σ의 가우시안 정책이면 KL에 비례). `--anchor-w 1.0` |
| PPO가 정책을 크게 흔듦 | PPO 환경 4개 중 2개는 도시, 2개는 시골로 고정(롤아웃 배치마다 50:50), 학습률 1e-4 → 3e-5, PPO 뒤 짧은 **정리 단계**(모델이 운전 + 기준 제어기 정답 + 도시 anchor) |
| OOD 통계가 도시만 | 섞기 학습 데이터(도시+시골)로 `obs_stats` 계산 |
| 관문 | 위 3절의 허용치(시골 +5 이상일 때만 도시 -1.0) — 시나리오별 안전 조건은 그대로 |
| 실제 시골길 없음 | 경기 양평군 서종면 정배리 OSM 3개 경로를 벤치마크·학습(시골길 표본의 35%)에 추가 |
| 농기계 | 사용자 요청으로 제거. 일반 차량 흐름(속도 제각각 앞차·마주 오는 차·옆길 진입 차·허용 구간 앞지르기)으로 바꿈 → 벤치마크 v2 |
