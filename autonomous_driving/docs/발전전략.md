# 자율주행 지능을 빠르게 키우는 방법 (발전 전략)

이 문서는 `autonomous_driving/`을 분석한 결과와, 매번 조금씩 더 잘 달리게 만드는 **개선 반복(continual improvement loop)** 설계,
그리고 앞으로의 계획을 정리해요. 숫자는 2026-10-30 상자 CPU(8코어)에서 잰 값이에요.

## 1. 지금 상태 분석

| 부분 | 현재 | 한계 |
|---|---|---|
| 차 모델 | 운동학 자전거 모델 + 마찰 한계(μg) | 타이어 미끄러짐·하중 이동 없음. 빠른 코너는 실제보다 쉬움 |
| 센서 | 2D 광선 15개(라이다 비슷), 밤에는 거리↓·잡음↑ | 카메라 없음. 신호 색·제한속도는 '지도'에서 바로 받음(인식 문제는 건너뜀) |
| 도로 | 합성 서킷, OSM 실제 도로(강남역·대치동), 절차 생성 시골길 | 교차로 안 차로 구조·다른 차 흐름이 단순 |
| 규칙 | 우측 통행, 안전속도 5030, 어린이보호구역 30, 신호, 우회전 일시정지, 시골길 시야·양보 | 보행자 신호, 유턴, 차로 변경 규칙 없음 |
| 기준 제어기 | Pure Pursuit + 속도 계획(굽이·제한·신호·시야) + 장애물 피하기·따라가기 | 손으로 짠 규칙이라 새 상황에 약함 |
| 학습 모델 | PPO(MLP 128×128), BC/DAgger로 시작 | 아직 기준 제어기보다 못함(아래 표) |

### 병목(가장 먼저 풀어야 할 것)

1. **보상 설계보다 '시작점'이 중요**: 아무것도 모르는 PPO는 몇 분 안에 규칙(신호·제한속도)을 배우지 못해요.
   그래서 기준 제어기를 흉내 내는 BC로 시작하고, DAgger(모델이 직접 달린 상황에 정답을 붙이기)로 '자기 실수에서 회복'을 배우게 했어요.
2. **드문 상황(빨간불·우회전·정차 차량·마주 오는 차)의 데이터가 적음** → 실패 사례 수집기가 실패 지점 40 m 앞에서 다시 시작하는 장면을 학습에 25% 섞어요.
3. **평가가 흔들리면 개선인지 알 수 없음** → 시드를 고정한 벤치마크(도시 10개 + 시골길 4개)와 승격 규칙(점수↑, 어디서도 회귀 없음)을 만들었어요.
4. **CPU 시간**: 환경 한 스텝이 파이썬이라 초당 약 1,500~2,000 스텝(4개 환경). 더 크게 키우려면 벡터화(numpy 배치)나 Kaggle T4가 필요해요.

## 2. 개선 반복(improve.py) 설계

```
best.zip ─┬─▶ DAgger/BC (기준 제어기 = 선생님, β를 0.5→0.03으로 줄여 가며 모델이 운전)
          │        └─ 후보 ①
          ├─▶ PPO 미세조정 (커리큘럼 + 도메인 무작위화 + 실패 사례 25%)
          │        └─ 후보 ②
          ├─▶ 고정 벤치마크 점수표 (완주·이탈·차선 편차·과속·어린이보호구역·신호·우회전·중앙선·부드러움·시골길 지표)
          ├─▶ 승격 판단: 점수 +0.5 이상 & 어느 시나리오도 새 이탈·위반·완주율 하락·점수 -5 없음 & (시골길 단계) 도시 점수 하락 없음
          └─▶ results/leaderboard.(csv|md), results/failures.jsonl (다음 사이클 학습에 섞음)
```

- **커리큘럼**: ① 쉬운 트랙 → ② 센 굽이·좁은 길·젖은 노면 → ③ 실제 한국 도로 + 규칙 + 장애물 → ④ 시골길. 30%는 앞 단계도 섞어서 잊어버림을 막아요.
- **도메인 무작위화**: 노면 마찰 0.5~1.0, 라이다 잡음 0~0.15 m, 제한속도 30/40/50/60, 신호 개수·위상, 트랙 모양·폭, 시작 위치·속도.
- **이어 학습**: 매 사이클 `weights/best.zip`에서 시작(warm start). 처음엔 BC로 시작.
- **실행**: `python improve.py --budget-minutes 5` (사이클 1번), `--cycles 3`, 시골길 단계는 `--rural`.

## 3. 결과 (CPU, 사이클당 학습 약 5분 + 평가)

| 모델 | 총점 | 도시 | 시골길 | 완주 | 이탈 | 신호·우회전 위반 | 과속(s) | 어린이보호구역 과속(s) | 시골길 위험 | 승격 |
|---|---|---|---|---|---|---|---|---|---|---|
| pure_pursuit(기준) | 96.97 | 97.86 | 94.77 | 14/14 | 0 | 0 | 0.0 | 0.0 | 0 | - |
| cycle1 | 25.01 | 38.4 | -8.48 | 6/14 | 8 | 2 | 162.8 | 11.2 | 1 | yes |
| cycle2(ppo) | 57.67 | 74.25 | 16.22 | 9/14 | 5 | 2 | 8.3 | 4.0 | 2 | yes |
| cycle3(bc) | 58.7 | 80.29 | 4.72 | 8/14 | 6 | 1 | 6.2 | 3.7 | 1 | no |
| cycle4-rural(bc) | 54.33 | 52.16 | 59.76 | 8/14 | 6 | 1 | 8.3 | 3.8 | 1 | no |
| cycle5-rural(ppo) | 62.93 | 71.73 | 40.92 | 10/14 | 4 | 3 | 5.9 | 5.9 | 1 | no |

- **전(cycle1, 첫 모델) → 후(cycle2, 현재 최고)**: 총점 25.0 → 57.7, 도시 38.4 → 74.3, 완주 6/14 → 9/14, 이탈 8 → 5, 과속 162.8 s → 8.3 s.
- cycle3(도시 80.3)과 시골길 cycle4·5(시골길 16.2 → 59.8 / 40.9)는 점수가 오른 곳이 있었지만 **다른 시나리오가 나빠져서(회귀) 승격 거절** — 승격 규칙이 의도대로 동작했어요. 특히 시골길 학습 때 도시 점수가 74.3 → 52.2 / 71.7로 떨어져서 막혔어요(도시 회귀 금지).
- 몇 분짜리 CPU 학습이라 아직 기준 제어기(총점 97.0)에 못 미쳐요. 다음 단계는 `docs/발전전략.md` 참고.
- cycle2는 승격 판단을 처음에 시골길까지 넣어 했다가(아직 시골길을 배우기 전이라 불공정) 거절됐고, 도시 단계는 도시 벤치마크로만 판단하도록 고친 뒤 같은 후보를 다시 판단해 승격했어요.


- 기준 제어기(사람이 짠 규칙)가 아직 가장 좋아요. 학습 모델은 사이클마다 확실히 오르고 있지만, 몇 분 학습으로는 장애물·우회전 같은 드문 상황이 부족해요.
- 자율 모드는 점수표 기준(완주 95% 이상, 이탈 0, 위반 0)을 넘을 때만 켜지게 해 두어서, 지금은 **기준 미달이면 자동으로 기준 제어기**로 달려요.
  `--force`로 모델을 켜면 안전 감시기가 위험할 때마다 기준 제어기로 넘겨서(개입 요청) 결과적으로 이탈·위반 없이 완주하는 것을 확인했어요.

## 4. 무료 Kaggle T4에서 돌리는 법 (직접 실행은 안 함)

1. 이 폴더를 Kaggle 노트북에 올리고(데이터셋 또는 `git clone`), `pip install gymnasium stable-baselines3 pyyaml networkx`.
2. `python improve.py --budget-minutes 60 --cycles 4 --n-envs 8` (MLP라 GPU 이득은 작아요. CPU 코어 수가 더 중요해서 `--n-envs`를 코어 수에 맞추세요).
3. 끝나면 `weights/best.zip`과 `results/`만 내려받아요. **가중치는 저장소에 올리지 않아요**(`.gitignore`).
4. 덕 학습과 무료 GPU 한도(주 30시간)를 나눠 쓰니, 덕 일정과 겹치지 않게 시간을 정하세요.

## 5. 앞으로 계획 (빠른 순)

1. **매주 자동 사이클**: 정해진 시간에 `improve.py --budget-minutes 30`을 돌려 리더보드에 한 줄씩 쌓기(승격 규칙이 있어 나빠질 걱정 없음).
2. **병렬·벡터화**: 라이다·투영을 배치로 계산하고 `SubprocVecEnv`로 코어를 다 쓰기 → 같은 시간에 3~5배 데이터.
3. **관측 개선**: 장애물 2~3개, 신호 남은 시간, 앞 50 m 제한속도 미리 보기. 큰 네트워크 + 관측 정규화(VecNormalize).
4. **보상 대신 제약**: 규칙 위반은 '벌점'보다 '안전 필터(기준 제어기로 바꾸기)'로 막고, 학습은 효율·부드러움에 집중.
5. **카메라 인식**: 위에서 본 그림 대신 차 앞 카메라 이미지(간단한 렌더링)로 차선·신호를 보고 판단 → CNN 정책.
6. **3D 시뮬레이터**: 무료 [CARLA](https://carla.org/)(한국 도로는 OSM→OpenDRIVE 변환), [Donkey Car 시뮬레이터](https://docs.donkeycar.com/), 교통 흐름은 [SUMO](https://eclipse.dev/sumo/).
7. **덕과 잇기**: `duck_skills_korean/`의 한국어 명령("앞으로 가", "멈춰", "학교 앞이야 천천히")을 이 차의 목표 속도·모드 전환에 연결.
