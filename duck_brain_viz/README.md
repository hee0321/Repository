# 덕의 신경망 (Duck Brain Viz)

Microduck이 시뮬레이션에서 걷는 동안 **걷기 정책 인공신경망**의 뉴런 활동을 3D 뇌 모양으로 보여 주는 정적 웹페이지예요.
현희님의 '신경속' 3D 뇌 시각화(three.js)의 뇌 모양과 신경섬유 배경을 그대로 가져와 썼고, 장난감 스파이킹 시뮬레이션 대신 실제 기록 데이터를 재생해요.

- 바로 보기: https://hee0321.github.io/Repository/
- 실제 뇌가 아니에요. 덕의 인공신경망 층을 뇌 부위에 나눠 배치한 비유예요.

## 무엇을 보여 주나요
- 정책: Kaggle 무료 T4로 이어 학습한 velstand `model_6850.pt`의 actor (MLP 61 → 512 → 256 → 128 → 14, ELU)
- 롤아웃: 상자 CPU에서 MuJoCo로 18초 (서기 2초 → 직진 5초 → 왼쪽으로 돌기 4초 → 제자리 오른쪽 돌기 4초 → 직진 3초). `microduck_rl_training/kaggle/full_run_v4/render_walk.py`와 같은 명령 계획이에요.
- 매 제어 스텝(50 Hz)을 2스텝마다 기록해서 25 fps, 450프레임이에요. 같은 롤아웃에서 영상도 함께 렌더링해서 화면 오른쪽 영상과 뉴런 활동이 정확히 맞아요.
- 기록한 신경망 값은 정책 출력과 최대 오차 3e-7로 일치하는지 확인했어요.

## 배치 (신경망 층 → 뇌 부위)
| 신경망 | 뉴런 수 | 뇌 부위 |
|---|---|---|
| 입력: 몸 회전 속도, 중력 방향(기울기), 걷기·머리·몸 명령 | 6 + 13 | 시상 |
| 입력: 관절 각도, 관절 속도 | 14 + 14 | 두정엽 |
| 입력: 직전 출력(동작 기억) | 14 | 후두엽 |
| 은닉층 1 | 512 | 전두엽 |
| 은닉층 2 | 256 | 측두엽 |
| 은닉층 3 | 128 | 소뇌 |
| 출력: 관절 14개 목표 각도 (왼다리 5, 목·머리 4, 오른다리 5) | 14 | 뇌간 |

- 밝기: 입력·출력은 값의 크기(정규화된 관측, 행동값), 은닉층은 ELU 출력의 양수 부분이에요. 층마다 상위 8% 값을 최대 밝기로 맞췄어요. 주황은 양수, 하늘색은 음수예요.
- 선과 펄스: 그 순간 `|가중치 × 앞층 활동|`이 가장 큰 연결을 층 사이마다 28개씩 그려요. 펄스가 입력에서 출력으로 차례로 흐르는 건 보기 좋게 표현한 것이고, 실제 계산은 한 스텝 안에 한 번에 끝나요.

## 파일
- `src/anatomy.ts`: '신경속'의 뇌 모양·신경섬유 코드 (그대로 재사용)
- `src/net.ts`: 신경망 뉴런을 뇌 부위에 배치
- `src/main.ts`: 재생, 타임라인, 영상 동기화, 관절 패널
- `public/data/activity.json`: 기록 데이터 (값 ×100 정수, 약 2.3MB), `public/data/walk.mp4`: 같은 롤아웃 영상
- `recording/record_activity.py`: 기록 스크립트 (microduck_rl 환경에서 `python record_activity.py model_6850.pt out/`)
- `screenshots/`: 서기, 직진, 왼쪽·오른쪽 돌기, 모바일 화면

## 실행
