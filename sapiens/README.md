# 사피엔스 · 사고의 실험실

현희의 작은 생각 워크벤치. 노트, 결정, 봇이 한 책상 위에 모입니다.

Warm paper 톤의 한국어 우선 단일 페이지. Next.js App Router + TypeScript + Tailwind CSS.

## 요구 사항

- Node.js 20+ (권장)
- 패키지 매니저: bun (권장), 또는 다른 Node 패키지 매니저

## 설치 & 실행

```bash
cd /workspace/sapiens
bun install
bun run dev
```

개발 서버: http://localhost:3000

## 빌드

```bash
bun run build
```

미리보기: bun run start

## 구성

- src/app/ — App Router 레이아웃·페이지
- src/components/ — Hero, About, Projects(실험대), Contact 등

연락 메일은 hello@sapiens.local 스텁입니다. 실제 주소로 교체하세요.
